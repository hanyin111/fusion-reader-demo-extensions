# 聚阅原创阅读演示

独立的公开演示仓库，仅提供专门创作的三篇短篇：山间来信、纸上旅行、晨光札记，共九章。

在应用内手动添加索引地址：

https://hanyin111.github.io/fusion-reader-demo-extensions/index.json

安装「聚阅原创阅读演示」，在发现页选择该来源。支持搜索、作者检索、小说阅读、收藏、历史及缓存。

正文随演示脚本提供，安装后阅读正文无需调用第三方内容接口。封面为自制图案，首次显示时从本仓库下载。应用本体不内置此仓库地址。

本仓库不提供账号服务、不采集阅读记录、不关联其他内容仓库。文字、脚本及图案按 MIT 许可提供。

验证：`node --test tests/*.mjs`；构建静态仓库：`python tools/build.py`。
